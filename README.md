# Gully Labs — Hand Lasted Indian Sneakers

An authentic web experience clone of **[Gully Labs](https://gullylabs.com/)** — Indian hand-lasted footwear rooted in vernacular culture, storytelling, and craftsmanship.

## Features

- **Responsive Streetwear UI**: Built with pure semantic HTML5, modern CSS3, and vanilla JavaScript.
- **Dynamic Multi-Currency Switcher**: Real-time conversions between INR (₹), USD ($), EUR (€), GBP (£), and AED.
- **Interactive Shoppable Lookbook**: Interactive pulsing hotspot pins that reveal product cards with instant "Add to Cart".
- **Hero Carousel Banner**: Multi-slide editorial banners with auto-play, manual controls, and progress counters.
- **Dual-Angle Hover Crossfade**: Displays alternate shoe profile angles on hover.
- **Quick View Modal**: High-res multi-angle image gallery with thumbnail picker, material notes, and size selection.
- **Slide-Out Cart Drawer**:
  - Live subtotal and items calculation
  - Free shipping progress bar toward the ₹5,000 threshold
  - Promo code discounts (e.g., `GULLY10` for 10% off)
- **Instant Search Drawer**: Live search filter across silhouettes, materials, and categories.
- **Footwear Size Guide Modal**: International size conversion table (UK, US, EU, CM) with measurement guidelines.
- **Simulated Checkout Flow**: Full shipping address form, payment options (UPI, Card, NetBanking, COD), and order confirmation.

## Technology Stack

- **Frontend**: HTML5, CSS3, Vanilla ES6 JavaScript
- **Catalog Data**: `data/products.js` (JSON-backed authentic data model)
- **Deployment**: Vercel
